# Text Diff

貼り付けたテキストの差分をその場で表示する、広告なし・依存なしの軽量な差分ツールです。

- テキストはブラウザ内だけで処理されます。外部への送信や保存は一切しません
- ビルド工程も外部ライブラリもありません。`index.html` を直接開くだけでも動きます

## 使い方

- A・B の欄にテキストを貼り付けると、入力に合わせて差分が自動で表示されます
- 「＋ テキストを追加」で比較対象を C, D… と増やせます（✕ で削除できます）
- テキストが3つ以上あるときは、比較方式を選べます
  - **基準(A) vs 他**：A と B、A と C… のように、A を基準に比べる
  - **隣同士**：A と B、B と C… のように、隣り合うテキストを順に比べる
- 表示は **インライン** と **左右並べ** を切り替えられます（画面幅が狭いときはインラインで表示します）
- 「空白の違いを無視」をオンにすると、連続する空白や行頭・行末の空白の違いを差分として扱いません
- 変更行の中で実際に変わった文字は、濃い色で強調されます
- 変更のない部分が長いときは折りたたまれます。クリックすると展開します

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目（ダークモード対応） |
| `diff.js` | 差分アルゴリズム（Myers 法、線形空間版）。DOM に依存しません |
| `app.js` | UI |
| `test/diff.test.js` | `diff.js` のテスト |

## テスト

Node.js 18 以上で、依存のインストールなしに実行できます。

```sh
node --test
```

## GitHub Pages で公開する

1. このリポジトリを GitHub に push します
2. リポジトリの **Settings → Pages** を開きます
3. **Build and deployment** の Source に「Deploy from a branch」を選び、Branch に `main` と `/ (root)` を指定して保存します
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

`.nojekyll` は、GitHub Pages の Jekyll 処理を無効にするための空ファイルです。
